
# Telecom AI Support Chatbot

## Overview
AI powered telecom chatbot using LangChain and LangGraph.

## Features

• FastAPI backend
• Streamlit frontend
• Vector database retrieval
• Tool calling
• Memory support

## Run Backend

uvicorn app:app --reload

## Run Frontend

streamlit run frontend.py

## API Endpoints

GET /
GET /health
POST /chat
